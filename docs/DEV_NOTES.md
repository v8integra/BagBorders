# BagBorders development notes

Feature-by-feature notes from development (moved out of the README for release). The phase plan and in-game checklists are in `BAG_WINDOW_PLAN.md`.

## Status

Features 1-3 were confirmed in-game on the beta; the 70790 bank fix below is not yet confirmed in game. Currently implemented:

- TOC manifest and SavedVariables-backed core namespace (`Core/Core.lua`), with a `db`-ready callback system for modules to hook into once SavedVariables are loaded.
- **Feature 1: Per-Bag Border Coloring** (`Modules/ContainerColors.lua`) — while Combined Bags mode is active, every item slot gets a colored outer border keyed to its originating bag. General bags cycle through a saturated 4-color palette (ADD-blended for visibility against the dark slot background) in bag-setup order; special bags (quiver/ammo pouch, detected via `bagFamily`) always get a fixed gold border regardless of position. The border is a new texture layered outside Blizzard's own item-quality border, so it never visually conflicts with rarity coloring. Hooks the `ContainerFrameCombinedBags` frame instance directly (`Update`/`UpdateItemSlots`) so coloring stays in sync automatically on open, close, and item changes — no manual refresh needed. `/bagborders debug` and `/bagborders refresh` are available for troubleshooting.
- **Feature 2 (minimal): Per-Bag Free Slot Count** — a small `(N)` label, color-matched to its bag's border color, on the first slot of each bag group in the combined view, showing free slots for that bag. Added because Blizzard's own native empty-slot display turned out to be buggy in this beta build (only correct on hover; otherwise shows an unrelated item's stack count). Computed directly via `C_Container.GetContainerNumFreeSlots`, not scraped from Blizzard's UI.
- **Feature 2b: Bag Bar Free Slot Count** (`Modules/BagBar.lua`) — same idea, applied to the equipped-bag icons on the main bag bar (`MainMenuBarBackpackButton`, `CharacterBag0-3Slot`, `CharacterReagentBag0Slot`). The backpack icon shows the *combined* free-slot total across all general bags; each special (quiver/ammo pouch) bag shows its own count on its own icon; the reagent bag always shows its own count (teal) on its own icon, since it's never part of that general total. Labels sit top-right, clear of Blizzard's own bottom-right item count. Refreshes on `BAG_UPDATE_DELAYED` (the same event Blizzard's own bag-slot buttons use), not by hooking any Blizzard function.
- **Feature 3: Combined Window Slot Order** (`Modules/CombinedLayout.lua`) — a build after 70170 changed the combined view's item sort to ascending while the grid still fills from the bottom-right corner, so the backpack ended up at the bottom and bags/slots ran backwards. A post-hook on the frame's `UpdateItemLayout` re-sorts descending and re-lays the grid out, restoring the original look (backpack first at the top, then the other bags in order). It's a no-op if Blizzard fixes the sort themselves.
  - **Removed in launch build 70790: reagent bag inside the combined window.** It worked by setting Blizzard's `ENDING_BAG_INDEX` global, which taints it. The bank's `OnShow` opens the bags first, reads that global, and the rest of its setup then runs tainted, so the restricted `C_Bank` calls refuse and the bank window stays blank. The reagent bag is back in its own window. Rule for this addon: never write Blizzard globals. (Fix not yet confirmed in game.)
- **Feature 4: Reagent Bag Dock** (`Modules/ReagentDock.lua`) — replaces the fold-in. The reagent bag keeps its own Blizzard window, but whenever Blizzard re-anchors the bag windows (a `hooksecurefunc` post-hook on `UpdateContainerFrameAnchors`), BagBorders moves it flush against the combined window: directly above it with right edges aligned when there's room, otherwise to its left with tops aligned. It only moves the window; it never opens/closes bags or writes Blizzard values, so it can't taint the bank. To make the reagent bag open together with the combined bags, every key bound to Toggle Backpack is pointed at Blizzard's Open All Bags command with an override binding (combined mode only, re-applied when keybinds or the combined-bags setting change, deferred until out of combat). Blizzard's own binding does the opening, so it stays untainted. Override bindings aren't saved, so the real keybinds are untouched. `/bagborders reagentkey` turns it off/on (setting `openReagentWithBackpack`). Clicking the backpack icon on the bag bar isn't covered and still opens only the combined window (changing that button's click would taint the bag-open path); bank, vendors and Open All Bags open both. Combined mode only; not in gamepad mode. Docking confirmed in game (sits above the combined window); the key override is mock-tested only.

- **Feature 5: All-in-one bag window** (`UI/BagWindow.lua`, `UI/Takeover.lua`, plan in `docs/BAG_WINDOW_PLAN.md`) — Phase 0 spike, confirmed in game 2026-11-05 (bags, bank, vendor, in-combat item use, no errors). Replaces Blizzard's bag windows (combined and individual modes) with one window: bags, then a reagent section, then the keyring if the account has one. It uses Blizzard's own item-button template, so clicks go through Blizzard's handlers. Blizzard still decides when bags are open; its windows are parked offscreen (not hidden) and ours mirrors them, and our X is a secure button that clicks Blizzard's own close. While it's on, the reagent dock, the Toggle Backpack key override, and the combined-window coloring/relayout all stand down. `/bagborders window` + `/reload` toggles it; `/bagborders columns <4-30>` sets the width. Phase 1 (confirmed in game): `/bagborders scale <0.5-2>`, `/bagborders lock`, `/bagborders reset`.

- **Feature 6: Bank window** (`UI/BankWindow.lua`, `UI/BankTakeover.lua`) — Phase 2, confirmed in game 2026-11-05. Replaces Blizzard's bank panel: every character bank tab as a section with free counts and tab-colored borders, the bank-bag slots, Sort, and (account bank) a Bank/Account view switch and Deposit all. Blizzard's panel stays open offscreen (its `SetPoint` is post-hooked) and ours mirrors it; the X secure-clicks Blizzard's close. "Blizzard bank" brings Blizzard's panel back for buying slots, money and tab settings. Details and limits in `docs/BAG_WINDOW_PLAN.md`.

- **Feature 7: Finding things** (`UI/BagWindow.lua`, `UI/BagStrip.lua`, `Modules/ItemLevel.lua`): Phase 3, confirmed in game 2026-11-05. The bag window gets a search box that uses Blizzard's own item search, so non-matches dim in the bags and the open bank, and the search clears when the bags close. It also gets a Sort button (`C_Container.SortBags`) and a bag strip (toggled by the bag icon next to Sort) showing the backpack, bags and reagent bag in their border colors with free counts. In the strip, hovering a bag lights up its slots, clicking a bag hides or shows its slots, dragging a bag off unequips it, and dropping a bag on a slot equips it. Hidden bags only stay hidden while the strip is open, so nothing can get lost. Gear (weapons, armor, rings, necks, trinkets; not shirts or tabards) shows its item level in the bottom-left corner, tinted by quality, in both windows; `/bagborders ilvl` toggles it. Quality borders, new-item glow and the junk coin come from Blizzard's item-button template.

- **Feature 8: Options page** (`Options/Options.lua`): Phase 4, confirmed in game 2026-11-05. Options > AddOns > BagBorders, or just `/bagborders`. It covers: the window on/off switch (with a Reload UI button), bag and bank columns, scale, background opacity, lock, reset position, the bag strip, item levels, and the Toggle Backpack reagent key. Built with Blizzard's Settings API. The page and the slash commands share the same saved settings.

- **Feature 9: Alts** (`Data/Characters.lua`, `UI/AltViewer.lua`, `Modules/TooltipCounts.lua`): Phase 5, **not yet tested in game**. Remembers every character's bags, bank, money and the account bank. Bags are saved whenever they change; a bank is saved while it's open. The "Alts" button (or `/bagborders alts`) opens a read-only viewer: pick a character, then Bags, Bank or Account bank, with search and total gold. Item tooltips list how many of that item each character has, plus the account bank. Characters show up after you log in on them once, and their bank after you open it once. `/bagborders forget <name>` (or shift+right-click in the viewer) removes one.

## Installation (development)

Clone or symlink this folder into your WoW `Interface/AddOns` directory as `BagBorders`, then enable it at the character select screen.
